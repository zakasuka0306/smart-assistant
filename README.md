# Telegram Bot

Мой телеграм бот, написанный на python. В нём собраны несколько функций, которыми можно пользоваться прямо в телеграме.

## Возможности

* Погода
* Интересные факты
* Перевод текста
* Озвучка текста
* Сохранение истории запросов

## Как работает

Пользователь отправляет команду, после чего бот обрабатывает запрос и возвращает результат.

## Используемые технологии

Python, python-telegram-bot, requests, edge-tts, deep-translator.

## Структура проекта

main.py
requirements.txt
README.md

## Запуск

pip install -r requirements.txt
python main.py
